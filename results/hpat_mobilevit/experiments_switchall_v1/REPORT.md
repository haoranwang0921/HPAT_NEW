# 优化开关全开 vs 全关（XXS，P0 主点）

日期：2026-09-10　｜　P0 主点：4 核 / 10 GHz / 32×32 / 25 MiB / 64 GB/s　｜　XXS warm

## 1. 全开结果

| 映射 | 全关（当前全部冻结结果的基线） | **全开** | 时延变化 | 能耗变化 |
|---|---:|---:|---:|---:|
| **H1**（仅 Linear） | 0.629657 ms / 4.869590 mJ | **0.578386 ms / 3.220094 mJ** | **−8.14%** | **−33.87%** |
| **H3**（Linear+1×1+attn） | 0.799543 ms / 5.831783 mJ | **0.707694 ms / 3.770414 mJ** | **−11.49%** | **−35.35%** |
| D0（不受光子开关影响） | 0.492209 ms / 2.543469 mJ | 0.492209 ms / 2.543469 mJ | 0% | 0% |

相对匹配 D0 的比值：

| | 全关 | 全开 |
|---|---:|---:|
| H1 时延 / D0 | 1.28× | **1.175×** |
| H1 能耗 / D0 | 1.91× | **1.266×** |
| H3 时延 / D0 | 1.62× | **1.438×** |
| H3 能耗 / D0 | 2.29× | **1.482×** |

⇒ **全开是 HPAT 在现有实现下最接近电子基线的一次**（时延差 17.5%、能耗差 26.6%），但仍未超过手写 D0。

## 2. 逐开关消融：增益来自哪里

| 变体 | H1 ms | H1 mJ | H3 ms | H3 mJ |
|---|---:|---:|---:|---:|
| 全关（基线） | 0.6297 | 4.8696 | 0.7995 | 5.8318 |
| + `photonic_stage_pipeline` | 0.6288 | 4.8667 | 0.7806 | 5.7696 |
| **+ `accumulator_residency`** | **0.5801** | 4.6346 | **0.7278** | 5.4916 |
| + `dma_batch_fetch` | 0.6297 | 4.8696 | 0.7995 | 5.8318 |
| **+ `activity_gated_static`** | 0.6297 | **3.3827** | 0.7995 | **4.0657** |
| + `reduce_compute_overlap` | 0.6297 | 4.8696 | 0.7995 | 5.8318 |
| **全开** | **0.5784** | **3.2201** | **0.7077** | **3.7704** |
| D0 | 0.4922 | 2.5435 | — | — |

**结论**：
1. **时延增益几乎全部来自 `accumulator_residency`（M2）**：H1 −7.9%、H3 −9.0%。其余四个开关对 warm 时延贡献 ≈ 0。
2. **能耗增益几乎全部来自 `activity_gated_static`**：H1 −30.5%、H3 −30.3%，且**对时延零影响**。
3. `dma_batch_fetch` 在 warm 下**零效果** —— 因为 warm 权重全部命中缓存，不产生权重 DMA，而被摊销的正是权重 DMA 的固定开销。（其价值在 cold 帧：可省约 1.0 ms。）
4. `reduce_compute_overlap`（M1）单独无效，与 9-6 的结论一致（单条 scratch bus 是关键路径）。
5. `photonic_stage_pipeline` 贡献很小（H3 −2.4%、H1 −0.1%），因为光路时间 77% 被总线遮住。

## 3. 一个必须标注的对比

全开的 H1（0.5784 ms）**已快于边缘合理电子基线 A3（XXS 0.607594 ms）**。
但这个对比**不能直接引用**：P0 的片上带宽是 256 GB/s，而 A3 是 44.8 GB/s（按阵列喂数推定）。
此前实测该参数单独一项就能使电子基线时延变化 **54%**。⇒ 该"胜出"主要来自片上带宽口径差异，不是光子本身的优势。

公平的做法是：给 A3 施加同等优化（LLMCompass 侧无此开关），或把 P0 的片上带宽降到与 A3 同口径后重测。

## 4. 边界

- 开关全开仍是**架构级事件模型**输出，无硅实测。
- 只跑 XXS；XS/S 未跑全开。
- 能量不可与 LLMCompass 侧直接比较（两侧能量模型不同：HPAT 用 SimPhony 分组账本，LLMCompass 侧本轮无能量输出）。
