# 单核权重块内流水线轻量验证

2026-09-07。有效结果v2。XXS真实矩阵/卷积形状，32×32物理阵列、10GHz，每算子仅取一个权重子块及一个batch，不是完整算子/整网。两段正负输入分别流式执行并排空；写环10ps先完成。未修改主仿真器。

每级服务时间=当前成本模型的整块时间/(2M)，名义每级100ps；启动间隔等于服务时间，是未校准假设。三级资源独立，级间各一个输出信用槽：生产者开始前预留，消费者开始后释放。下游忙时反压上游；末端假定无限消费能力，不含数字差分/累加、共享总线与外存。

名义块内加速约2.96–3倍，是三级均衡且输入就绪的调度结果，不是器件验证。ADC服务时间扩大4倍的压力测试中，QKV串行691.21ns、流水461.21ns，约1.50倍；不能把该压力测试的名义动态能量列当成新ADC物理能耗。

检查通过：单token无加速；16token等时级符合18周期而非48周期；慢ADC导致上游停顿；输入就绪约束；级间信用容量约束；每token阶段依赖及资源不重叠；名义串行总时间与原后端块成本一致。未模拟权重切换的多块覆盖问题、数值精度或最终数字输出，不声称已验证整网。

名义动态能耗按原块活动次数保留。缓冲/控制成本未加入；未报告整网功耗和节能幅度。下一步应接入共享SRAM、数字归约和有限最终输出队列后再测H1/H3。
