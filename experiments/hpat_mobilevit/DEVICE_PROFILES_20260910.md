# 三档器件/系统 profile：第一轮可实现子集

日期：2026-09-10。此文件不替换冻结 H123，也不把新结果用于 iPhone 加速比。

## 实际采用的参数

| 参数 | P0：Conservative（用户指定） | P1：Balanced 子集 | P2：Optimistic 子集 |
| --- | --- | --- | --- |
| 物理阵列、频率 | 32×32、10 GHz | 同 P0 | 同 P0 |
| tile × core | 2×2 | 2×2 | 2×4 |
| 整阵列写入并稳定 | 10 ps 假设 | 同 P0 | 同 P0 |
| 每环写入能耗 | 保留 1 μs 模型事件能耗 | 不变 | 不变 |
| 编程 lane | 4 | 8 | 16 |
| 权重 SRAM | 1 MiB | 1 MiB | 2 MiB |
| 激活/部分和 scratchpad | 8 MiB | 8 MiB | 8 MiB |
| 外存带宽 | 512 GB/s | 相同 | 相同 |
| 片上总线 | 256 GB/s | 相同 | 相同 |
| DMA 启动 | 每次 100 ns | 每次 100 ns | 每次 100 ns |
| 权重打包突发上限 | 128 B | 512 B | 2048 B |
| 核内有限流水 | 关闭 | 每块 16 token 后排空 | 每块 32 token 后排空 |
| ADC | 8 bit、10 GSPS、14.8 mW | 相同 | 相同，未冒用未核实替代器件 |
| DAC | 8 bit、14 GSPS 参考点 50 mW | 相同 | 相同 |
| 光路损耗 | 原模型 | 不变 | 不变，待器件证据 |

未指定的阵列和频率沿用最近冻结实验的 32×32、10 GHz，而不是早期 16×16、5 GHz。
P0 的“Conservative”只是本轮标签：10 ps 和 512 GB/s 都不能据此宣称是保守手机配置。
本轮 P0 与历史 Phase 0 的 25 MiB、64 GB/s 不是同一点。

## 单位和器件出处

ADC：14.8 mW / 10 GSPS = 1.48 pJ/sample。
来源为 [ISSCC 2022 原论文（作者单位托管）](https://minghsiehece.usc.edu/wp-content/uploads/2024/03/ISSCC2022-Digest-210-12.pdf)，题名 A 10GS/s 8b 25fJ/c-s 2850um² Two-Step Time-Domain ADC…；8 bit 编码不意味着 8 ENOB。

DAC：50 mW / 14 GSPS = 3.5714 pJ/sample。模型在 10 GHz 按相同单次能耗计费，对应 35.714 mW 动态活动功率；不是仍按 50 mW/10 GSPS 得到 5 pJ/sample。
来源为 [VLSI 2020 原论文 DOI](https://doi.org/10.1109/VLSICIRCUITS18222.2020.9162776)，作者实验室的[出版清单](https://arbabianlab.stanford.edu/publications)亦收录该题名。

采样间隔不等于 ADC 首样本端到端转换延迟。本轮不以 1/fs 替换现有 SimPhony 转换服务时间；实际 encode/compute/convert 秒数存于各档 kernel_costs.json。转换流水填充和真实 ADC 的 II/latency 对应仍待验证。

检索到 CICC 2025 的 12.5 GSPS、14.7 mW ADC，见[官方会议程序](https://www.ieee-cicc.org/wp-content/uploads/2025/03/CICC-2025-Program-3-13-25-1.pdf)。其完整分辨率、精度、面积和延迟兼容性尚未核实，本轮不作为等精度替代器件，不拼接最佳数字。

## 新调度的边界

新代码独立于冻结文件。P1/P2 的权重按同一算子的缓存块顺序连续打包，这是新增编译器布局假设。需求缺失触发一个对齐突发，传输整段（包括可能已驻留的行），每次启动开销先支付，整段搬运和 SRAM 填充结束后才标记 ready。尾段不跨算子张量；缓存占用仍受容量约束。不是原 dma_batch_fetch 的算子末尾补缴启动延迟。

D0 与混合方案均使用同样的突发能力、电子吞吐和外存参数；D0 受益属于预期行为。
核内流水采用每级单服务资源、单输出 credit、背压和正负输入两次 pass；块结束排空。输入仍需先完成原有供数，输出仍走原有回收和数字归约。有限缓冲计入既有 scratchpad 容量，但新增控制器、寄存器与编程 driver 的面积/漏电未校准。因此 P1 仅保持相同物理 core/阵列预算，不能声明已证明整芯片严格等面积；P2 显式扩面积。

所有模式保留全推理时长静态功耗积分。未启用理想供数重叠、静态门控、免归约或免写环能耗。
编程 lane 多于 core 未必有收益；本轮不会为使其有效而改变其物理含义。

## 电子参照与实验范围

复用冻结点的理想电子参照：10 TOPS、利用率 1、MAC 0.4 pJ、静态 0.3 W。它不是新 iPhone 拟合模型，也不是历史另一次 D0 调整点（80%、0.9 pJ、0.5 W）。本轮只改变显式 profile 参数，同档 D0/H123 的电子系数一致。

先运行一个完整 QKV 算子，再运行 XXS192、batch=1 的 D0/H1/H2/H3 整网；冷帧和第二帧 warm 分开报告。FP32 shape trace + 8 bit 成本不是量化或非理想性准确率验证。确定性两帧不构成统计置信区间。

## 未完成项（不能写成已实现）

- 更高带宽且更低单次能耗的等精度 ADC、额外 DAC/ADC 并行硬件。
- 有器件/链路依据的低损耗配置和随之匹配的激光预算、精度检验。
- 编程 driver、pipeline buffer/control、SRAM 扩容的完整面积与漏电模型。
- 真实 ADC 首样本延迟/II 校准、实际连续权重布局与突发控制器验证。
- XS/S 整网、ImageNet 准确率和真实手机公平比较。

因此这是“三档可实现子集”的第一轮实验，不是三档完整文献验证器件方案。必须同时报告 D0、绝对延迟、单次能量及平均功率，不能只保留有利结果。
