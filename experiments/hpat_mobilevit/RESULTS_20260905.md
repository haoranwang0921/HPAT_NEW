## 主实验结果

以下为连续第 3 张输入的结果，单元格为 **延迟 ms / 单张能耗 mJ**。
这不是多次随机测量的均值，也不据此声称已经达到渐近稳态。

| 模型 | D0 全电子 | H1 静态 Linear | H2 再加入 1×1 Conv | H3 再加入 QKᵀ/AV |
| --- | ---: | ---: | ---: | ---: |
| MobileViT-XXS | 0.367 / 12.55 | 2.163 / 42.31 | 2.484 / 47.74 | 3.233 / 59.97 |
| MobileViT-XS | 2.139 / 53.66 | 5.699 / 114.68 | 6.987 / 137.38 | 8.541 / 162.92 |
| MobileViT-S | 4.810 / 108.26 | 13.521 / 258.14 | 16.354 / 307.90 | 19.296 / 356.59 |

H2 中的 1×1 Conv 指 `groups=1` 的逐点卷积。H3 的动态矩阵不能跨输入复用。
冷启动及全部映射结果均保留在图 1 和原始 CSV 中。

**本批主实验不支持“小规模 HPAT 比当前全电子基线更快或更节能”的结论。**
三个模型中，H1 均优于 H2，H2 均优于 H3；在本配置和调度方式下，扩大光子映射
范围会增加端到端成本。这是特定参数和实现范围内的结论，不能推广为所有光子架构无效。

## 扫描揭示的规律

1. 写环时延是关键成本。以 XS 的 H1 为例，写环从 1 μs 降到 0.1 μs，
   延迟由 5.699 降到 3.036 ms，能耗由 114.68 降到 71.85 mJ。
   这是探索性快写假设，不是已经实现的器件指标。
2. 增加写环并行通道能改善延迟和能耗，但四个物理核的容量仍然限制权重驻留。
   H3 每张图分别发生 9,810 / 19,159 / 41,856 次物理块编程事件。
3. 单独把编程事件能耗改成 0.5–2 倍，对总能耗的影响远小于改变写环时延。
   当前账本中，电子侧静态功率在整个推理期间持续积分，因此延长等待时间也增加能耗。
4. 权重 SRAM 增大可以降低绝对延迟，但全电子基线也受益。
   例如 XXS 从 1 MiB 增至 4 MiB 时，H3 从 3.233 降至 2.966 ms，D0 则从
   0.367 降至 0.101 ms。因此图中的 H3/D0 比值反而增大，不能误读为 SRAM 越大越慢。
5. 在本批所有单因素扫描点的第 3 张输入中，混合方案相对匹配 D0 的最小延迟比
   为 1.420，最小能耗比为 1.339；两者均出现在 XS、H1、0.1 μs 写环点。
   **本次已扫描范围内没有出现优势交叉点。** 未做多参数联合最优搜索。

## 结论的适用边界

主点为 4 个 16×16 物理阵列、固定面积正负权重行配对、正负输入分两次执行、
1 μs 写环、4 条编程通道、1 MiB 权重缓存和独立 8 MiB 激活/部分和缓冲。
电子侧使用 312 TFLOPS 名义峰值及 15 W 静态功率，HBM 为 512 GB/s。
这些是当前架构探索假设，不能称为一款真实移动 NPU 或 GPU 的实测配置。

调度为算子顺序派发和算子内部有限物理块并行，未实现原稿可能设想的跨算子优化、
细粒度双缓冲最优流水或自动掉电；实体化算子之间的激活搬运显式计费。
因此应先审查平台参数、DMA 突发、融合和流水实现，不能仅为复现旧稿加速比修改常数。

轨迹来自 FP32 随机权重模型的实际执行，逐层 MAC 与旧算子表一致；
8 bit 仅用于本批成本建模。没有执行分类准确率、量化误差或光学非理想性实验，
不得把旧准确率结果与本批配置直接合并成同一已验证实现。
