# HPAT experiment evidence boundary

Status: frozen artifact policy

Scope: anonymous `v1.0.1` experimental reproducibility release.

## Supported artifact results

- Architecture-level mapping opportunity under the declared reasonable-high
  boundary.
- Component-visible energy accounting from explicit unit-cost assumptions.
- A fixed 1,024-sample local non-ideality diagnostic across five seeds.
- Deterministic input, configuration, output, and environment manifests.

These results are local/modelled diagnostics. They do not establish measured
HPAT runtime, fabricated-silicon behavior, calibrated deployment energy,
mobile/edge deployment, production performance, or full-ImageNet robustness.

The canonical repeatability digest covers categorical prediction changes and
the released machine-readable summaries. Per-sample perturbed
confidence/margin floats remain integrity-hashed local diagnostics but are
non-canonical and are not distributed.

## Evidence lanes

| Lane | Status | Boundary |
| --- | --- | --- |
| P0-E1: silicon evidence | `blocked` | No fabricated-silicon evidence is included. |
| P0-E2: calibrated energy | `blocked` | Energy remains an explicit local model. |
| P0-E3: fixed-slice non-ideality | `paper_eligible_with_limitations` | Local/modelled diagnostic on the exact locked slice only. |
| P0-E4: comparable deployment evidence | `blocked` | No measured HPAT mobile/edge deployment result is included. |

The P0-E3 status name is retained from the frozen experiment protocol. It does
not imply that a manuscript is stored in or generated by this repository.

## Prohibited claim upgrades

The artifact must not be described as:

- silicon validation;
- measured HPAT speedup or energy;
- an edge/mobile deployment;
- calibrated physical-layout evidence;
- full-ImageNet robustness;
- broad cross-platform superiority.

## Release scope

The public Git tree and GitHub Release may contain only experimental code,
configuration, tests, bounded reference tables, sanitized run manifests, and
sanitized CSV/JSON diagnostics. They must not contain manuscripts, PDF, TeX,
publication artwork, review material, dataset images, weights, logits, device
traces, or personal metadata.
